Requirement 1: Players / Walls 
There needs to be a “character”/object on each side that can move independently to the other.

The “ball” needs to “bounce off” of the “character”/object.

The “character”/object should not be able to go off the top or bottom of the screen.

Both players should be allowed to use the keyboard. For instance, player 1 could use the W and S keys, while player 2 would use the Up and Down arrows.

All objects in your scene must be textured.

The ball needs to bounce off the top and bottom of the screen—unless your specific variation of pong has a mechanic through which it can. If that’s the case, please ask us first!

------------------------------------------------

Requirement 2: Single-Player Switch
If the player presses the t-key, one of the “characters”/objects should switch from player-controlled to a simple pre-determined motion (i.e. in a pattern; up and down, tracking the position of the ball, etc.). In other words, we are simulating the player switching from 2-player mode to 1-player mode. 

Make sure that the second user can't use their keys to move the paddle when in 1-player mode.

-----------------------------------

Requirement 3: Have an option to choose number of balls
Allow the player to press number keys from 1-3 and generate that number of “balls” on the screen (preferably, do generate more than 3). Players should be able to change the number of “balls” any time during the game.

HINT: Generate every object that could be on the screen at any given time, but any object that isn't currently being used should not be rendered nor updated.

------------------------------------------

Requirement 4: Game Over
The game should stop when someone wins or loses (whatever that may mean in your game).

The only requirement is that there must be a winning/losing condition.

Tips
To keep things simple, I'd recommend using box-to-box collision detection only.

Work object by object, mechanic by mechanic, and test often. This goes for all programming, but if you try finishing all objects in one go, you are bound to miss something that has a hard time finding it.
